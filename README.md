# غياب التعلّم عن بعد – متوسطة الشيخ عبدالله خياط

تطبيق مستقل تمامًا (قاعدة بيانات خاصة به، غير مرتبط بأي تطبيق آخر).
البيانات المخزنة فقط: اسم الطالب، المرحلة، الفصل، اسم المعلم، الحصة، وتاريخ الغياب.
لا توجد أرقام هويات ولا أرقام جوالات، والاستيراد يرفض أي ملف فيه أرقام طويلة.

## الملفات
- `index.html` التطبيق كاملًا (المعلم + لوحة الإدارة + التقارير)
- `schema.sql` إنشاء الجداول في مشروع Supabase المستقل

## الرموز الافتراضية
- رمز المعلمين: 4040
- رمز الإدارة: 5050
(تُغيَّر من CONFIG أعلى ملف index.html)

## النشر في GitHub Pages
1. أنشئ مستودعًا جديدًا داخل khayatschoole-dev باسم `remote-absence`
2. ارفع `index.html` و`README.md`
3. Settings ← Pages ← Branch: main ← Save
4. الرابط: https://khayatschoole-dev.github.io/remote-absence/

## أول تشغيل
1. ادخل بصفة الإدارة ← تبويب «الطلاب والجدول»
2. استورد الطلاب (اسم، مرحلة، فصل)
3. استورد الجدول (يوم، حصة، مرحلة، فصل، معلم) أو عدّله يدويًا لكل فصل
4. أرسل الرابط ورمز المعلمين للمعلمين

## قاعدة احتساب اليوم
يُحتسب الطالب غائبًا يومًا كاملًا إذا غاب أكثر من نصف حصص فصله المجدولة في ذلك اليوم
(7 حصص ← 4 حصص فأكثر). أقل من ذلك يظهر «غياب جزئي».
